# bcools.me

Portfolio personnel de Baptiste Cools — site statique servi par un hébergement OVH.

## État

Site HTML statique, sans build : les fichiers du dépôt sont ceux servis en ligne, tels quels.

| Page | Fichier |
|---|---|
| À propos (accueil) | `index.html` |
| Projets | `projets.html` |
| Contact | `contact.html` |

`assets/` contient le thème (Bootstrap 3, jQuery, Font Awesome, et-line, linea, owl.carousel),
`img/` les médias.

## Identité visuelle

À conserver lors de toute refonte :

| Rôle | Valeur |

| Structure sombre | `#2f3e4f` |

## Déploiement

À mettre en place : publication automatique vers l'hébergement OVH de `bcools.me`.
Les accès OVH ne sont **jamais** versionnés ici — ils vivent dans les secrets GitHub
et le Trousseau macOS.
